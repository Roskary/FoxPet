# FoxPet 红狐狸桌宠 🦊

这是一个基于 Python 和 PyQt5 纯手搓的桌面宠物项目。告别沉重老旧的 Java shimeji 框架，采用轻量级事件驱动重构。

## ✨ 目前已实现的功能
* 基础物理引擎（重力下落、踩地板检测）
* 鼠标交互（拖拽拎起、松手自由落体）
* 随机状态机（待机呼吸、随机左右走动）
* 视觉与物理完全解耦（丝滑移动 + 正常帧率动画）

🚀 Update: 2026-03-26 (Major Physics & Interaction Overhaul)
✨ 新增特性 (New Features)
全向攀爬系统 (Spider-Fox Mode)：引入全新的多维度状态机。桌宠现在不仅能在地面行走，还支持主动寻路攀爬（GO_TO_WALL）、垂直上下墙壁、以及无缝切换至天花板倒立漫步与挂壁发呆。

动能投掷引擎 (Fling Physics)：彻底重写鼠标拖拽交互。底层植入类似 VelocityTracker 的历史轨迹黑匣子（保留最近 0.1 秒的位移数据），精准捕捉玩家松手瞬间的爆发初速度。现在可以极其丝滑地将桌宠以抛物线“甩”飞，并动能吸附至屏幕边缘。

复合渲染滤镜 (Dynamic Transform)：放映机（animate）模块升级，接入复合 QTransform 矩阵。仅需一套基础序列帧，即可通过代码实时组合出“水平翻转（左右朝向）”与“垂直翻转（天花板倒立）”，彻底解放美术画图的劳动力。

🐛 修复与优化 (Fixes & Optimizations)
修复边缘鬼畜 Bug：重构了碰撞拦截逻辑，将粗暴的“撞墙反弹”升级为“位移预判 + 边距补偿（Padding）”，根治了桌宠在屏幕边缘卡死并疯狂原地掉头的穿模悖论。

实装虚空打捞机制 (OOB Failsafe)：添加了针对平流层与异次元死角的“安全网”。当桌宠被极高初速度甩出屏幕容差边界（±200px）时，会强制触发空间传送，使其在屏幕正上方重新进入自由落体状态，彻底杜绝实例丢失。
