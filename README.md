# FoxPet 红狐狸桌宠 🦊

这是一个基于 Python 和 PyQt5 纯手搓的桌面宠物项目。告别沉重老旧的 Java shimeji 框架，采用轻量级事件驱动重构。

## ✨ 目前已实现的功能
* 基础物理引擎（重力下落、踩地板检测）
* 鼠标交互（拖拽拎起、松手自由落体）
* 随机状态机（待机呼吸、随机左右走动）
* 视觉与物理完全解耦（丝滑移动 + 正常帧率动画）

## 编码环境
Python3.6 + PyQt5 5.15.2

1. 确保电脑里安装了 Python 环境（推荐 Python 3.8+）。
2. 在当前目录下打开终端 (Terminal / CMD)。
