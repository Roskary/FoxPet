# FoxPet 红狐狸桌宠 🦊

基于 PyQt5 开发的轻量级、纯物理驱动的桌面宠物引擎。

---
## 📥 如何下载游玩？

1. 找到 **[Releases]**，下载最新的 `.zip` 压缩包。
2. 将压缩包**解压到一个文件夹中**。
3. 双击运行 `FoxPet.exe`。
4. **退出与设置**：在电脑右下角的系统托盘找到狐狐图标，右键点击即可缩放体型或退出。

---

## 🎮 互动指南
*   **拖拽**：按住鼠标左键可以在空中提溜它。
*   **抛掷**：拖拽并快速松手，根据你的鼠标挥动速度，可以将它甩飞出去！
*   **戳一戳**：极速短促地点击它，会触发惊吓表情，并附带向后跃起的物理击退效果。

## ✨ 目前已实现的状态 (Implemented States)

### 🌲 1. 地面行动区 (Ground)
*   **`IDLE`**：原地发呆闲置。
*   **`STAND_TWO_FOOT` / `STAND_FOUR_FOOT`**：两脚站立与四脚趴伏状态。
*   **`STAND_UP` / `DROP_DOWN`**：起立与趴下的姿态切换过渡。
*   **`SIT`**：乖巧坐下。
*   **`BLINK` / `SMILE`**：原地眨眼与微笑互动。
*   **`WALK` / `WALK_FOUR_FOOT`**：两脚/四脚地面溜达，遇到屏幕边缘会自动掉头。
*   **`HUNT`**：捕猎扑击！包含预备蓄力、拔地而起的抛物线物理跃击，以及落地扑咬的完整表现。
*   **`GO_TO_WALL`**：自动寻找离自己最近的墙壁并跑过去。
*   **`JUMP_TO_WALL`**：起跳腾空并啪唧一下挂在墙上。
*   **`LAND`**：从高空坠落到地板时的落地缓冲动作。

### 🧱 2. 墙壁攀爬区 (Wall)
*   **`CLIMB_UP` / `CLIMB_DOWN`**：在屏幕左右两侧边缘垂直向上/向下攀爬。
*   **`WALL_IDLE`**：挂在墙上休息、东张西望或舔爪子。

### قف 3. 天花板倒立区 (Ceiling)
*   **`CEILING_ENTER` / `CEILING_EXIT`**： 墙角翻越过渡态。爬到墙顶或天花板边缘时转向。
*   **`CEILING_WALK`**：在屏幕最顶端倒立漫步。
*   **`CEILING_IDLE`**：倒立挂在天花板上发呆，或像钟摆一样惬意摇晃。

### 🖱️ 4. 鼠标互动区 (Interaction)
*   **`DRAG`**：被鼠标揪住时的空中悬吊、挣扎与张望。
*   **`FALL`**：松开鼠标或从天花板失足时的受重力自由落体。
*   **`POKED`**： 戳击反馈！鼠标极速短促点击狐狐，会触发惊吓表情，并附带向后跃起的物理击退效果。

## 🚀 开发者指南 (Developer Guide)

### 环境依赖
```bash
pip install PyQt5
```

## 📁 目录结构

```text
FoxPet/
├── main.py             # 程序入口
├── pet_entity.py       # 引擎核心 (物理运算、状态机驱动、GUI渲染)
├── conf.py             # 配置中枢 (动作参数、速度参数、状态转移概率)
├── icon.png            # 托盘图标
└── assets/             # 序列帧资源文件夹
```
