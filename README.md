# FoxPet 红狐狸桌宠 🦊

这是一个基于 Python 和 PyQt5 的半手搓桌面宠物项目。告别沉重老旧的 Java shimeji 框架，采用轻量级事件驱动重构。

---

## ✨ 目前已实现的功能 (Implemented States)

### 🌲 1. 地面行动区 (Ground)
*   **`IDLE`**：原地发呆闲置。
*   **`STAND_TWO_FOOT` / `STAND_FOUR_FOOT`**：两脚站立与四脚趴伏状态。
*   **`STAND_UP` / `DROP_DOWN`**：起立与趴下的姿态切换过渡。
*   **`SIT`**：乖巧坐下。
*   **`BLINK` / `SMILE`**：原地眨眼与微笑互动。
*   **`WALK` / `WALK_FOUR_FOOT`**：两脚/四脚地面溜达，遇到屏幕边缘会自动掉头。
*   **`HUNT`**：🦊 **[核心亮点]** 捕猎扑击！包含预备蓄力、拔地而起的抛物线物理跃击，以及落地扑咬的完整表现。
*   **`GO_TO_WALL`**：自动寻找离自己最近的墙壁并跑过去。
*   **`JUMP_TO_WALL`**：起跳腾空并啪唧一下挂在墙上。
*   **`LAND`**：从高空坠落到地板时的落地缓冲动作。

### 🧱 2. 墙壁攀爬区 (Wall)
*   **`CLIMB_UP` / `CLIMB_DOWN`**：在屏幕左右两侧边缘垂直向上/向下攀爬。
*   **`WALL_IDLE`**：挂在墙上休息、东张西望或舔爪子。

### قف 3. 天花板倒立区 (Ceiling)
*   **`CEILING_ENTER` / `CEILING_EXIT`**：🦊 **[核心亮点]** 墙角翻越过渡态。爬到墙顶或天花板边缘时，身体进行90度折叠翻越，并智能判断左右墙壁进行 AI 转向。
*   **`CEILING_WALK`**：在屏幕最顶端倒立漫步。
*   **`CEILING_IDLE`**：倒立挂在天花板上发呆，或像钟摆一样惬意摇晃。

### 🖱️ 4. 鼠标互动区 (Interaction)
*   **`DRAG`**：被鼠标揪住时的空中悬吊、挣扎与张望。
*   **`FALL`**：松开鼠标或从天花板失足时的受重力自由落体。
*   **`POKED`**：🦊 **[核心亮点]** 戳击反馈！鼠标极速短促点击狐狐，会触发惊吓表情，并附带向后跃起的物理击退效果。

---

## 🎮 互动指南

*   **左键拖拽**：在空中提溜它。
*   **拖拽并快速松手**：根据你的鼠标速度将它甩飞。
*   **极速短促点击**：触发 `POKED` (被戳) 状态，它会向后跳起躲避！
*   **系统托盘右键菜单**：支持一键召唤 (防走丢)、动态切换体型缩放 (75% / 100% / 150%) 以及退出程序。

## 🚀 快速开始 (Getting Started)

### 环境依赖
```bash
pip install PyQt5
```

### 运行项目
```bash
python main.py
```
*(注：请确保根目录下拥有 `icon.png` 以及 `assets/` 文件夹内存放有对应的动作序列帧)*

---

## 📁 目录结构

```text
FoxPet/
├── main.py             # 程序入口
├── pet_entity.py       # 引擎核心 (物理运算、状态机驱动、GUI渲染)
├── conf.py             # 配置中枢 (所有动作参数、速度参数、AI转移概率)
├── icon.png            # 托盘图标
└── assets/             # 存放所有 .png 序列帧资源的文件夹
```
